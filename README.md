🍽️ Family Meal Suggestions
Overview

Family Meal Suggestions is a web-based family meal voting application that allows family members to suggest and vote on meal options for breakfast, lunch, and dinner.

The application was developed to simplify family meal planning by collecting preferences from multiple family members and displaying the results in a single location.

Users can:

Enter their name or nickname.
Review and accept Terms & Conditions.
Vote on meal choices.
Submit allergies, dietary restrictions, or foods they do not eat.
View a summary of family voting results.

The application is hosted online using Firebase Hosting and stores data in Firebase Firestore.

System Workflow
User enters a name or nickname.
User accepts the Terms & Conditions.
User selects meal preferences.
User submits dietary restrictions if applicable.
Data is stored in Firestore.
User is redirected to the results page.
Results are displayed to all users accessing the application.
